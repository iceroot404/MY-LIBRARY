МАССОВАЯ ЗАГРУЗКА КНИГ ЧЕРЕЗ TELEGRAM

1. Распакуйте эти файлы в корень проекта MY-LIBRARY, чтобы install_bulk_import.py лежал рядом с main.py.
2. В терминале перейдите в папку проекта и активируйте окружение:
   cd ~/Desktop/my_library
   source .venv/bin/activate
3. Запустите установщик:
   python install_bulk_import.py
4. Проверьте синтаксис:
   python -m py_compile bot/admin_bot.py bot/bulk_import.py
5. Перезапустите бота/сайт:
   python main.py

В Telegram откройте панель управления и нажмите «Массовая загрузка» либо отправьте /bulk.

ТРИ РЕЖИМА:
1) Обложки сначала: отправьте все изображения, нажмите «Начать отправку книг», затем отправьте книги в том же порядке. Если обложки нет, бот попробует найти её сам.
2) По очереди: обложка -> соответствующая книга -> следующая обложка -> следующая книга. Для книги без обложки отправьте /skipcover.
3) Только книги: отправляйте файлы, бот попробует найти обложки самостоятельно.

Команды: /bulk — начать; /books — перейти от обложек к книгам в режиме 1; /skipcover — пропустить обложку в режиме 2; /finish — завершить; /bulkcancel — отменить.

Поддерживаются PDF, EPUB, FB2, DJVU, TXT и обложки JPG/JPEG/PNG/WEBP.
Для EPUB и FB2 бот читает встроенные название и автора. В остальных форматах название берётся из имени файла; можно добавить подпись в виде «Название — Автор».

ВАЖНЫЕ ОГРАНИЧЕНИЯ:
- Через стандартный облачный Telegram Bot API бот может скачивать файлы до 20 МБ каждый. Более крупные файлы нужно загружать через сайт или настраивать локальный Telegram Bot API Server.
- Автопоиск обложки использует Open Library. Он не гарантирует точное совпадение; если подходящая обложка не найдена, книга добавится без неё.
- В режиме 1 важно сохранить одинаковый порядок обложек и книг.
- В режиме 2 порядок строго: обложка, затем файл книги.
