# My Library — добавленные возможности и оставшиеся работы

## Добавлено в этот комплект

- Единая стилизация карточек каталога, одинаковая геометрия обложек.
- Сортировка каталога по новизне, популярности, названию и автору; категории и поиск.
- Автоматическая «Книга дня» и подборка рекомендаций.
- Страницы авторов со списком их книг.
- Книжные полки «Хочу прочитать», «Читаю», «Прочитано».
- Закладки, запоминание места чтения, настройки шрифта и темы (для поддерживаемых форматов).
- Личные заметки и цитаты в читалке.
- Обсуждения книг, ответы, лайки и жалобы.
- Статистика чтения, годовые цели и календарь чтения.
- Личные коллекции и публичная ссылка на общую полку.
- Книжные клубы: создание, вступление и публикация сообщений через API.
- Сравнение 2–4 книг в каталоге.
- Жалобы на ошибочные данные книги.
- Админ-статистика, блокировка пользователей, модерация и журнал части административных действий.
- Корзина книг с восстановлением: удаление не стирает файлы и запись из БД.
- CSV-экспорт каталога и импорт метаданных.
- Резервные копии базы и папки загрузок через `scripts/backup.py`.
- PWA-манифест и Service Worker; посещённые страницы и некоторые файлы могут кэшироваться для офлайн-доступа.
- Telegram: три режима массовой загрузки, поиск обложек Open Library, защита от дубликатов, прогресс и итоговый отчёт.
- Telegram: `/catalog`, `/search`, `/popular`, `/new`, `/random`, `/profile`, `/history`, `/requests`, `/link`.
- Связь аккаунта сайта и Telegram по одноразовому коду; уведомления о статусе заявок и добавлении заказанной книги.

## Что требует отдельного следующего этапа

Ниже перечислены идеи из общего плана, которые в этом пакете не реализованы полностью: физический обмен/выдача книг между пользователями; семейные аккаунты с несколькими участниками и разными правами (сейчас общая полка доступна по ссылке только для чтения); полноценные биографии и фотографии авторов из внешних источников; издательство/ISBN/язык/год как отдельные поля и фильтры; интерактивное выделение любого текста во всех форматах; полноценная система уведомлений с пользовательскими настройками; XLSX-экспорт; отдельный визуальный интерфейс клубных обсуждений; подробная аналитика календаря по дням/месяцам; админ-интерфейс для каждой операции модерации и всех журналов; синхронизация всех команд Telegram с каждой операцией сайта.

Обмен цифровыми файлами между читателями намеренно не включён: библиотека должна распространять только материалы, на которые есть разрешение.

## Ограничения

- Офлайн-доступ зависит от браузерного хранилища: кэш может очищаться браузером и не гарантирован для любого файла.
- CSV-импорт создаёт записи с метаданными, но не переносит содержимое книг/обложек.
- Массовая загрузка через облачный Telegram Bot API ограничена размером скачиваемого ботом файла (20 МБ).
- Автоматический поиск обложки может не найти книгу или найти недостаточно точное совпадение; в таком случае запись остаётся без найденной обложки.
- Для работающих ссылок на сайт внутри Telegram укажите публичный адрес `SITE_URL` в `.env`.


## Персональный дизайн и фирменный стиль (добавлено в этом обновлении)

- Персональные настройки каждого аккаунта: светлая/тёмная/сепия, свой акцентный цвет, фон (однотонный/бумага/градиент/собственное изображение), семейство шрифтов, размер текста и стиль карточек.
- Загрузка собственного аватара и обложки профиля. Настройки разделены по user_id и не влияют на других читателей.
- Страница `/settings` с формами сохранения внешнего вида и профиля.
- Смена темы с главной страницы сохраняется в аккаунте через API; для незарегистрированных посетителей используется localStorage.
- Панель `/admin#design`: смена названия сайта, главного заголовка/подзаголовка, фирменного цвета, логотипа, favicon и фонового изображения баннера.
- Страницы `/help`, `/privacy`, `/terms`, `/contact`; в шаблонах присутствуют общие ссылки и динамическое имя бренда.
- Добавлен `web/static/css/personalization.css` с мобильной адаптацией, вариантами оформления и поддержкой prefers-reduced-motion.

## Что перед публичным запуском всё ещё обязательно проверить/доделать

- Заполнить реальные контакты владельца, юридическую информацию, политику обработки персональных данных и процедуру удаления аккаунта/данных. Шаблоны legal-страниц являются стартовым текстом, а не юридической консультацией.
- Настроить HTTPS, безопасные cookie (`https_only=True`), секреты `.env`, CSRF-защиту форм и лимиты загрузки на уровне reverse proxy.
- Проверить внешние библиотеки EPUB/PWA при отсутствии сети и выбрать self-hosting для полного офлайна.
- Реализовать все оставшиеся элементы, отмеченные выше как отдельный этап: ISBN/язык/год/издатель, полный интерфейс книжных клубов и модерации, семейные роли, XLSX, расширенная аналитика.
- Проверить права на каждую публикуемую книгу и обложку.

- Межстрочный интервал и ширина колонки текста настраиваются отдельно; настройки сохраняются на аккаунте и мигрируют автоматически для существующей SQLite базы.
