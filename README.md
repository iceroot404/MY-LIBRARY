# My Library — Telegram bot + animated admin panel

## Требования
- Python 3.10+
- Telegram bot token от [@BotFather](https://t.me/BotFather)
- Ваш Telegram numeric ID

## Установка

```bash
# 1. Распакуйте архив и перейдите в папку my_library
python -m venv .venv

# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:
- `BOT_TOKEN` — токен Telegram-бота
- `ADMIN_ID` — ваш числовой Telegram ID
- `ADMIN_PASSWORD` — пароль входа в веб-админку
- `SESSION_SECRET` — длинная случайная строка (не менее 32 символов)

Запуск:

```bash
python main.py
```

Откройте:
- Сайт: http://127.0.0.1:8000
- Админ-панель: http://127.0.0.1:8000/admin/login
- Проверка сервера: http://127.0.0.1:8000/health

## Команды Telegram
- `/start` — меню администратора
- `/add` — пошаговое добавление книги
- `/list` — последние 50 книг
- `/stats` — статистика
- `/delete 5` — удалить книгу с ID 5
- `/cancel` — отменить текущий ввод

Бот принимает фото обложки и документы PDF, EPUB, FB2, DJVU, TXT (до 50 МБ).
Веб-панель позволяет добавлять книги и удалять записи. Все данные хранятся в SQLite в `library.db`, загруженные файлы — в `web/static/uploads/`.

## Важно для публикации в интернете
1. Измените `ADMIN_PASSWORD` и `SESSION_SECRET`.
2. Используйте HTTPS и установите `COOKIE_SECURE=true` в `.env` после включения HTTPS. При локальной разработке оставьте `COOKIE_SECURE=false`.
3. Не публикуйте `.env`, токен бота и базу данных в Git.
4. Для production запускайте приложение через ASGI-сервер за reverse proxy.


## Дополнительные функции библиотеки

В обновлении добавлены:
- книжные полки читателя: «Хочу прочитать», «Читаю», «Прочитано»;
- закладки и регулировка размера шрифта в TXT/EPUB-читалке;
- обсуждения книг, ответы, лайки и жалобы;
- центр книжных полок и статистика чтения в личном кабинете;
- расширенная админ-статистика, управление блокировкой читателей и модерация отзывов/жалоб;
- сортировка каталога по новизне, популярности, названию и автору;
- резервное копирование SQLite и папки загрузок.

### Резервные копии

Создать копию вручную:

```bash
source .venv/bin/activate
python scripts/backup.py
```

Настроить ежедневную копию в 03:15:

```bash
bash scripts/install_backup_cron.sh
```

Копии хранятся в `backups/`, сохраняются последние 14 папок. Для текущей конфигурации SQLite копируются база данных и файлы из `web/static/uploads/`.


## Расширенный комплект возможностей

В комплект добавлены книжные полки, закладки, заметки/цитаты, обсуждения, цели чтения, календарь чтения, коллекции с публичной ссылкой, книжные клубы, рекомендации, книга дня, страницы авторов, сравнение книг через API, жалобы, корзина книг, CSV экспорт/импорт, журнал действий, PWA-кэш и команды читателя Telegram.

Для ссылок из Telegram добавьте в `.env` публичный адрес сайта (с HTTPS):

```env
SITE_URL=https://ваш-домен.example
```

Связь аккаунта сайта с Telegram: откройте профиль сайта, создайте код, затем отправьте Telegram-боту `/link КОД`. Команды читателя: `/catalog`, `/search`, `/popular`, `/new`, `/random`, `/profile`, `/history`, `/requests`. Администратор по-прежнему использует `/panel` и `/bulk`.

PWA: откройте сайт в браузере и используйте его команду «Установить приложение». Файлы книг кэшируются после первого открытия/скачивания при наличии места в хранилище браузера; офлайн-доступ не гарантируется, если браузер очистил кэш или сервер ограничил хранение.

CSV содержит метаданные, но не копирует бинарные файлы книг и обложек. Импорт CSV добавляет только записи каталога; файлы нужно загрузить отдельно.

### Предпубликационная проверка
После настройки `.env` выполните:

```bash
python scripts/preflight.py
```

Скрипт проверяет наличие ключевых переменных и папок, не выводя значения секретов. `COOKIE_SECURE=true` требуется только после включения HTTPS.
